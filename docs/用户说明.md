# CT3D用户说明文档

## 版本信息
- 版本：1.23.1
- 更新日期：2026-11-01
- 作者：wmw

## 软件简介

CT3D是一款专业的CT影像阅片与三维重建软件，支持DICOM格式的CT/MR影像数据加载、二维阅片、多平面重建（MPR）和三维体渲染。软件采用深色医疗风格界面，提供直观高效的影像分析工具。

**v1.7.0 起并入 X 线辅助诊断能力**：同一份患者列表里同时显示 CT 与 X 线（DR）检查，
载入 X 线后可用胸片检测、骨折检测、脊柱侧弯（Cobb 角）、骨龄评估、足弓测量等 AI 辅助功能。

界面提供**四套皮肤**（石墨 / 墨蓝 / 象牙 / 青瓷），点右侧「工具区」标题旁的
**皮肤**按钮即可一键切换，选择会记住，下次启动沿用。

软件提供**两种阅片模式**：

- **二维阅读（默认）** —— 单视图大画面阅片，适合逐层观察、快速浏览
- **三维重建** —— 四视图（MPR + 体渲染），适合立体结构分析

加载序列后**默认进入二维阅读模式**，可随时手动切换到三维重建。
（X 线为单帧投影影像，只有二维阅读，三维重建对其不可用。）

## 系统要求

- 操作系统：Windows 7/10/11
- 内存：8GB以上（推荐16GB）
- 显卡：支持OpenGL的独立显卡（推荐）
- 硬盘空间：根据数据量而定
- Python版本：3.8.10

## 主要功能

### 1. 患者列表管理

#### 患者列表排序
- **位置**：左侧患者列表区域上方
- **功能**：按文件修改时间排序患者列表
- **选项**：
  - **最新在前**（默认）：最新的患者显示在最上方
  - **最早在前**：最早的患者显示在最上方

#### 序列缩略图（v1.6.0 新增）
- 展开患者后，每个序列以**缩略图卡片**呈现，无需加载即可预览内容
- 卡片包含：
  - 左侧 **96×96 预览图**（自动取序列中段信息量最丰富的一层）
  - 第一行：`序列N · 张数 · 检查部位`
  - 第二行：层厚、序列描述
- 预览图按序列自带的窗宽窗位显示；生成在后台进行，
  打开软件后卡片会先显示"预览"占位图，随后自动替换为真实图像
- 鼠标悬停卡片可查看完整序列信息与所在目录
- 双击卡片即加载该序列（与原来的行为一致）
- **按住卡片拖到右侧阅片区域也可直接打开**（v1.7.7 新增）：
  - 拖动时阅读区顶部出现蓝色边框、中央提示「松开即可打开该序列」，
    松手即加载，与双击效果完全一致
  - 只有**序列卡片**可以拖动；患者姓名行不支持拖动
  - 拖放与双击共用同一套解析逻辑，患者姓名、性别、检查号、检查日期
    都会正常带入（骨龄评估需要性别，写检测记录需要检查号）
  - 三维模式下同样可拖放（四视图区域也能接收）

#### 一键删除所有患者
- **位置**：左侧患者列表区域上方，红色"删除全部"按钮
- **功能**：删除扫描目录中的所有患者文件夹
- **注意**：
  - 操作前会弹出确认对话框
  - 删除后数据不可恢复，请谨慎操作
  - 删除成功后会显示统计信息

### 2. 数据加载

#### 自动扫描
软件启动时会自动扫描以下默认目录：
- `D:\Cache`
- `D:\ClearTmp\DicomTmp`

#### 手动加载
- 点击右侧工具栏"加载患者目录"按钮
- 选择包含DICOM文件的文件夹
- 支持加载单个患者或整个目录

#### 加载序列
- **单击患者姓名**：展开/收起该患者的序列列表，直接看到各序列的缩略图
  （此操作**不会**加载图像，可快速浏览）
- **双击序列卡片**：加载该序列
- **拖动序列卡片到阅片区域**：同样可加载该序列（v1.7.7 新增，见上文
  「序列缩略图」）
- 加载完成后默认以**二维阅读**模式显示

> **提示**：加载前软件会自动过滤目录中的非 DICOM 文件，
> 若目录中混有设备生成的临时文件（如 `ko`、`*.xml`）不会影响加载。

### 3. 二维阅读模式（默认）

#### 多窗对比显示（v1.9.0 新增）

阅读区上方的「窗口：**1 / 2 / 4**」按钮可切换显示布局：

| 布局 | 用途 |
|------|------|
| **1 窗** | 常规阅片，画面最大（默认） |
| **2 窗** | 左右并排，适合对比两个序列（如 T1 vs T2） |
| **4 窗** | 四宫格，一屏看完多个序列（如 T1/T2/FLAIR/DWI） |

**每个窗口都是独立的**，各自有自己的序列、当前层、窗宽窗位、缩放与平移：

> **打开不在患者列表里的片子**：把DICOM 文件（或整个序列文件夹）
> 直接从桌面 / 资源管理器**拖到软件窗口任意位置**即可打开；
> 也可以点右侧「**打开 DICOM 文件**」按钮来选。
> 没有 `.dcm` 后缀的 DICOM 文件同样能识别。
> 打开失败时会有明确提示（不会静默无反应）。

> **「加载患者目录」怎么用**：选到**患者数据根目录**（里面是各个患者的
> 子文件夹）会刷新左侧列表；选到**只含一个序列的目录**才会直接打开。
> 若目录里混放了多个序列（有些设备会把颈/胸/腰等序列放在同一层），
> 会按患者目录处理并刷出列表，避免只读到其中一部分。
> 从 **PACS 导出**的目录也认：整目录的 DICOM 会先探检查类型再读
> （X 线/DR 按 X 线读，不会读成一小块黑图）；**整目录的常见图片**
> （PNG / JPG 等）会当一个图片序列读入，**可翻层**；图片按序列分在几个
> 子目录里时，会弹窗列出各子目录的张数，确认后加载张数最多的那个。
> 打开失败时会有明确提示（不会静默无反应）。

> **「加载患者目录」怎么用**：选到**患者数据根目录**（里面是各个患者的
> 子文件夹）会刷新左侧列表；选到**只含一个序列的目录**才会直接打开。
> 若目录里混放了多个序列（有些设备会把颈/胸/腰等序列放在同一层），
> 会按患者目录处理并刷出列表，避免只读到其中一部分。

- **载入选中的窗口**：两种方式任选
  - **拖放**：直接把序列卡**拖到目标窗**里 —— 放到哪个窗就载入哪个窗，
    不会动到其他窗已载入的序列；
  - **双击**：先用鼠标点一下目标窗（会亮起**蓝色边框**表示当前活动窗口），
    再双击左侧序列卡片，序列就载入到这个窗；
- **各窗数据独立**：往某个窗载入新序列**不会**影响其他窗已载入的序列，
  各窗可以同时显示不同序列；
- **各窗数据独立**：往某个窗载入新序列**不会**影响其他窗已载入的序列，
  各窗可以同时显示不同序列；
- **各窗窗值独立**：在某个窗上调了窗宽窗位只影响它自己，
  不会把其他窗调好的对比度抹掉；
- **翻层独立**：滚轮、方向键、右侧滑条都只作用于活动窗口；
- **测量只作用于活动窗口**：CT 值、长度、角度测量都在蓝框窗口里进行；
- **窗口同步**：模式栏「窗口：1/2/4」右边有 **「同步」** 勾选框。
  勾选后，**在任意一个窗口翻层或调窗宽窗位，其余窗口会跟着一起动**，
  方便逐层对比。典型用法：
  - **a 窗肺窗、b 窗纵隔窗** —— 同步翻层，逐层看同一位置在两种窗下的表现；
  - **MRI：a 窗 T1、b 窗 FLAIR** —— 同步翻层，对读两个序列。

  说明：
  - 两个序列**层数不同**时会按**比例**对齐（第1 层对第 1 层、
    末层对末层），尽量对到相同的解剖位置；
  - 没载入图像的空窗口、隐藏的窗口不参与同步；
  - 按 **R 键**复位窗值**不会**影响其他窗口（各窗默认窗值本就不同）；
  - 不需要联动时取消勾选即可，各窗口完全独立；
  - **数据保留**：从 4 窗切回 1 窗再切回来，各窗口的序列都还在，
    方便来回对比（隐藏的窗口不会丢数据）；
- **AI 标注**：只显示在活动窗口（X 线检测结果只针对刚检测的那张片子）。

> 提示：多窗下每个画面较小，测量精度会下降。需要精细测量时切回 1 窗。
> 窗口数按钮只在二维模式显示，切到三维重建时自动隐藏。

#### 界面布局
- **主画面**：单个大视图，逐层显示轴位切片
- **右侧滑条**：纵向浏览条，拖动即可滑动浏览整个序列（层数大于 1 时显示）
  - 顶部为第 1 层，向下为后续层
  - 滚轮、方向键、缩略图跳层时滑条会自动同步到当前层
- **底部缩略图条**：显示整个序列的缩略图（点击"序列"按钮展开/收起）
- **四角信息**：
  - 左上：患者姓名 / ID
  - 右上：序列描述 / 当前窗宽窗位
  - 左下：当前层号 / 总层数 / 层物理位置（mm）
  - 右下：模态 / 层厚 / 像素间距
- **左右标识**：画面左侧为"右"，右侧为"左"（符合阅片习惯）

> **默认窗宽窗位**：打开序列时会自动采用该序列自身记录的
> DICOM 窗宽窗位（W/L），与设备阅片效果一致；若设备未记录，
> 则按部位自动选择（胸部 1500/-600，其余 400/40）。

> 首次切换到三维重建时软件会弹出「正在构建三维视图」的忙碌提示，请等待提示消失后再操作。

#### 测量工具（v1.6.2 新增，v1.13.0 图标化）
视图区左下角新增测量工具栏（在「全屏 / 序列」按钮右侧）：**CT值 / 长度 / 角度**（三个工具互斥，点「清除」移除全部标记）。

> **v1.13.0 起这些按钮都是图标了**（CT值 = 圆形十字、长度 = 尺寸线、
> 角度 = 折线圆弧、清除 = 垃圾桶）。**鼠标停在按钮上会弹出中文说明**，
> 不用再猜哪个是哪个。

- **CT值（圆形 ROI 区域平均）**：点击图像任意位置放置圆心，软件自动圈出一个圆形区域，
  显示**圆内平均 HU 值**（同时标注半径 mm 与像素数 n），比单点测量更抗噪声、更准确。
  圆形半径可调整：**CT 工具激活时滚动滚轮**（或按 `[` / `]`）即可放大 / 缩小圆圈，
  调整后会自动重算平均 HU。鼠标移动时光标旁会实时显示当前位置的单点 CT 值。
- **长度**：依次单击两点，软件自动测量并标注两点间的直线距离（单位 mm）。
- **角度**：依次单击三点（第一条射线的端点 → 顶点 → 第二条射线的端点），软件标注顶点处的夹角（单位 deg）。
- 测量结果按当前层保存，**翻层后只显示本层的测量标记**；平移、缩放、调窗时测量图形会自动跟随解剖结构。
- 需要平移 / 缩放时，即使测量工具已激活，仍可用**中键拖动**或 **Ctrl + 滚轮**操作。
- 调整 CT 圆形半径时翻层仍可用右侧滑条（滚轮在 CT 工具下已用于调整半径）。

> **三维窗口也能量长度了**（v1.13.0 新增）：见上文「三维长度测量（测长）」。
> 二维量的是当前层的平面距离，三维量的是模型表面两点的**空间直线距离**。

#### 缩略图条
- 点击左下角"序列"按钮显示或隐藏
- 当前层在缩略图条中以蓝色边框高亮
- 直接点击任意缩略图可跳转到该层

### 4. 模式切换

#### 切换方式
- **顶部模式栏**：点击"二维阅读"或"三维重建"按钮
- **快捷键**：按 `W` 键在两种模式间切换
- **右侧工具栏**：使用"显示模式"下拉框

#### 模式说明
- **二维阅读**：单视图阅片，工具最少，专注逐层观察
- **三维重建**：四视图（轴位 / 矢状位 / 冠状位 / 3D 体渲染），
  首次切换时需要构建三维管线，会有短暂等待

> 切回二维模式后三维管线会保留在内存中，再次切换无需重新构建。

### 5. 三维重建模式

#### 四视图布局
- **左上**：轴位（Axial）视图
- **右上**：矢状位（Sagittal）视图
- **左下**：冠状位（Coronal）视图
- **右下**：3D体渲染视图

#### 视图交互
- **左键拖动**：移动光标位置
- **右键拖动**：调整窗宽窗位
- **中键拖动**：缩放视图
- **滚轮**：切换切片（轴位/矢状位/冠状位）
- **左下角按钮**：全屏/退出全屏

#### 三维工具按钮（左下角一排，鼠标悬停看说明）
所有工具按钮都是**图标**形式，**鼠标停在上面会弹出中文说明**：

| 图标 | 作用 |
|---|---|
| 四宫格 | 保存多视角（一次导出前/后/左/右/上/下六个角度的 PNG） |
| 相机 | 截图（保存当前视角为单张 PNG） |
| 剪刀（黄色） | 切割：用左键在模型上圈画要删掉的部分，松开即删除 |
| 逆时针箭头 | 撤销上一次切割 |
| 顺时针箭头 | 重置，恢复切割前的完整模型 |
| 立方体+蓝线 | 测长：在模型上点两点量距离 |
| 尺寸线+红叉 | 清测量：清除三维窗口里所有测量 |

#### 三维长度测量（测长）
1. 点左下角的**立方体+蓝线**按钮进入测量模式
2. 在模型上**点第一下**、**再点第二下**，两点间的距离（毫米）会标在连线中点
3. 可以继续点下一组，测量结果会累积
4. 点**尺寸线+红叉**按钮清除全部测量

> 测量时**按住左键拖动仍可旋转视角**（方便转到不同部位取点）。
> 标签始终正对相机，转动模型也不会看不清。
> 如果载入的是普通图片（PNG/JPG）而不是 DICOM，图像没有真实物理尺寸，
> 读数会显示为「像素」而不是毫米。

#### 光标同步
- 所有视图的光标位置实时同步
- 在任意视图中移动光标，其他视图自动更新

### 6. 窗宽窗位调节

#### 预设选项
- **肺窗**：WW:1500, WL:-600
- **纵膈窗**：WW:400, WL:40
- **骨窗**：WW:1500, WL:300
- **脑窗**：WW:80, WL:40

#### 自定义调节
- 使用右侧工具栏的WW（窗宽）和WL（窗位）数值框
- 在二维阅读中右键拖动
- 在MPR视图中右键拖动

> 窗宽窗位在两种模式间实时同步：无论在哪一侧调整，切换模式后都会保持。

### 7. 三维重建参数

#### 骨组织阈值调节
- **滑动条**：范围50-500 HU
- **预设选项**：
  - 四肢骨：200 HU
  - 肋骨：150 HU
  - 脊柱：180 HU
  - 颅脑：250 HU
  - 骨盆：200 HU

#### 其他选项
- **去除细小碎屑**（默认开启）：只剔除远离骨块的漂浮噪点（对比剂血管段、
  重建噪斑等）；骨表面 6 个体素内的噪声壳层与细节纹理受邻接保护，
  不会破坏骨质感（头颅、关节表面的细颗粒纹理均可完整保留）
- **自动去床板**：按 CT 密度自动识别床体并整块移除（床板的碳纤维板、
  塑料、泡沫垫、U 型托架、护栏，以及检查床与 FOV 边界伪影融合成的
  包裹壳——胸部等大 FOV 序列的"床板去不掉"多由它造成），位于身体外侧
  的床块还会向图像外缘整体切除（含支柱、碎段残留），不会误切患者组织

#### 颜色模式
- **默认骨色**：明亮的米黄色
- **GE骨白**：类似GE设备的骨白色

### 8. MPR切片同步

- **滑动条**：范围0-100%
- **功能**：

  - 二维模式下：可直接拖动跳转到指定层

### 9. X 线辅助诊断（v1.7.0 新增）

#### 患者列表里的 CT 与 DR

患者列表**同时显示 CT 与 X 线检查**，靠姓名前的方括号前缀区分：

| 前缀 | 含义 |
|---|---|
| `[CT]` | CT 检查 |
| `[DR]` | X 线检查（DR/DX/CR） |
| `[CT+DR]` | 该患者同时有 CT 和 X 线 |

X 线序列卡片以**体位名**为主标题，例如 `1. 颈椎正位`、`2. 腰椎侧位`
（一幅片子就是一个序列）。双击卡片即可加载。

> X 线为单帧投影影像，**仅支持二维阅读**。载入后三维按钮会变为
> 「三维重建（X线不可用）」并禁用，右侧的 CT 值测量工具也会关闭
> （X 线没有 HU 物理意义）。
>
> **画面极性**：部分 DR 设备按 `MONOCHROME1`（负片）存档，软件会自动反相，
> 显示效果与常规阅片一致（**骨头亮、背景暗**）。若载入后发现整幅明暗相反，
> 说明该片子的极性标记异常，可反馈具体文件。

#### AI 辅助诊断按钮

载入 X 线影像后，**右侧工具栏底部**出现「X线 AI 辅助诊断」分组：

| 按钮 | 适用部位 | 输出 |
|---|---|---|
| **智能识别并检测** | 任意 | 按 DICOM 检查部位自动选择下面的某一项并执行 |
| **胸片检测** | 胸部 | 14 类病变（心脏肥大、胸腔积液、气胸、结节等）定位与置信度 |
| **骨折检测** | 四肢 / 关节 / 脊柱 / 足部 | 骨折位置与置信度 |
| **脊柱侧弯** | 全脊柱正位 | 椎体识别 + **Cobb 角**及侧弯程度分级 |
| **骨龄评估** | 左手腕片 | RUS-CHN（中华 05 标准）**骨龄**、各关节等级与得分 |
| **足弓测量** | 足部 X 线 | 5 个足弓关键点、**内侧/外侧足弓角** |
| **微调关键点** | 足弓测量后 / 脊柱侧弯后 | 切原始影像显示手柄（足弓 P1~P5、脊柱上下终板线四个端点），可拖动，角度实时更新 |
| **复位关键点** | 足弓测量后 / 脊柱侧弯后 | 把手柄恢复成模型原始提取的位置 |
| **清除 AI 标注** | — | 撤掉图上的标注，恢复原始影像 |
| **检测设置** | — | 调整各项检测的置信度阈值（越低越敏感） |
| **检测记录** | — | 查看 / 搜索 / 删除 / 导出历史检测记录 |
| **漏检反馈** | 任意 X 线 | 模型漏检或结果不对时，登记当前片子作为改进素材 |
| **反馈列表** | — | 查看 / 导出已登记的反馈，点「已登记 N 条」旁可打开 |

> **按部位自动过滤（v1.9.1）**
> 载入 X 线后，软件会先读 DICOM 的检查部位（BodyPartExamined，读不到时
> 依次用序列名、检查描述推断），**只放开适用于该部位的检测按钮**，
> 其余按钮置灰，鼠标悬停会写明原因。例如胸片只放开「胸片检测」，
> 足弓测量、骨龄评估、脊柱侧弯都不可用 —— 这些模型在胸片上也能跑出一个
> 数字，但数值没有临床意义，比直接报错更容易误导。
>
> **足弓 / 脊柱测量的手动微调（v1.9.5、v1.9.6）**
> 模型给出的定位点（足弓五个点）或终板线端点（脊柱四个点）会有几像素偏差，
> 为此不需要重新训练模型，可以直接拖动微调、拖动即时刷新角度
> （详见「更新日志 v1.9.5」「更新日志 v1.9.6」）。
>
> 分组顶部会写明当前部位与可用项（如「当前部位：胸部，可用：胸片检测」）。
> 「智能识别并检测」在判不出部位时**不会**自动执行，避免选错模型。
>
> 若设备未写（或写错）检查部位、导致本该可用的功能被置灰，可到
> 「检测设置」里勾选「**忽略部位匹配限制**」放开全部按钮 —— 此时请自行
> 确认片子与所选项目是否匹配。
>
> **儿童胸片的心影校正（v1.9.3）**
> 儿童（15 岁以下）胸片上，心影本来就比成人相对大，而检测模型是按成人标准
> 训练的，所以过去**几乎每张儿童胸片都会被判「心脏肥大」**。现在软件会读
> DICOM 里的患者年龄，对「心脏肥大」这一项单独做二次判断：
>
> - 估计出心胸比、且**未超过**该年龄的生理上限（<1 岁 0.60 / 1~4 岁 0.55 /
>   ≥5 岁 0.50）→ 改标为「**心影偏大（儿童生理性）**」，框变成灰色，
>   **不再计入「检出 N 处病变」**，但仍列出来供你参考，置信度也照常显示；
> - 真的超出该年龄上限 → 照常报「心脏肥大」，并在说明里给出估计值与上限；
> - 有的片子不满足测量条件、估不出心胸比 → 标为「**心影偏大（未能核实）**」，
>   同样不计入病变数，请结合临床判断；
> - 15 岁及以上、或读不到年龄 → **不校正**，与以前完全一致。
>
> 结果区会多出一行浅色说明，写明用的年龄、估计的心胸比和该年龄的上限，
> 便于核对。这一项只影响「心脏肥大」，其余 13 类病变（积液、气胸、结节、
> 不透明等）的判定完全不受影响。
>
> 需要对照旧行为时，可在「检测设置」里取消勾选
> 「**儿童胸片心影校正（按儿科心胸比标准）**」。

#### 结果怎么看

- 检测完成后，**标注直接画在图像上**（中文标签、Cobb 角弧线等），
  与原始影像同一位置、同一方向；
- 按钮下方显示**关键指标**（如 `Cobb角 19.0°`、`骨龄 12.34 岁`）与文字结论；
- 再往下的**结果列表**逐条列出检出的病变 / 关节 / 关键点与置信度；
- 点「清除 AI 标注」可随时回到原始影像，不影响已保存的记录。

#### 检测记录

- 每次检测完成会自动写入记录（时间、患者、类型、结论、关键指标）；
- 「检测记录」对话框支持按姓名/检查号/摘要搜索、按类型筛选、分页浏览、
  删除选中、清空、导出 CSV；
- 对话框内的「**清理历史图像数据**」用于回收磁盘空间：旧版记录把整张标注图
  也存进了数据库，长期使用可能占用数 GB。该操作会**先备份后清理**，
  只丢弃图像、保留全部记录信息（图像随时可重新检测得到）。

#### 漏检反馈（模型没识别出来时）

有骨折却没被标出来、或结果明显不对时，点「**漏检反馈**」把当前这张片子
登记下来，作为后续优化模型的素材：

1. 载入 X 线影像后，「漏检反馈」按钮变为可用；
2. 点它会弹出登记框，**当前片子的信息已自动带好**（患者姓名、检查号、
   检查日期、检查部位、文件名，以及你刚才跑的那次检测和它的结果）；
3. 选一个**反馈类型**（骨折漏检 / 其他漏检 / 误报 / 结果不正确），
   备注可写可不写 —— 只有类型是必填的；
4. 点「提交反馈」即完成。

登记后会发生两件事：

- **图片存到软件目录** `feedback_images\日期\`（如
  `feedback_images\20261004\204732_xxxx.png`），按日期分文件夹存放；
  存的是**骨头亮的正片**（负片会自动纠正），可直接用于训练；
- **记录写进数据库**，含时间、类型、患者信息、部位、备注、来源文件路径、
  当时用的检测功能与结果。

点「**反馈列表**」可以搜索（姓名/检查号/部位/备注）、按类型筛选、翻页、
双击查看保存的图片、导出 CSV（Excel 可直接打开）。删除记录时磁盘上的图片
也会一并清理。

> 说明：图片**只存文件不进数据库**，数据库里只记路径，所以登记反馈
> 不会让数据库体积膨胀（这与「检测记录」里那个占用数 GB 的旧问题不同）。

## 注意事项

1. **数据备份**：删除患者文件夹前请确认已备份重要数据
2. **阈值选择**：不同部位使用不同的骨阈值，可参考预设选项；默认 200 HU，加载序列后不再按年龄自动调整
3. **低功耗模式**：开启后滑动时图像质量会降低，释放后恢复
4. **首次切换三维**：需要构建三维管线，会有短暂等待属正常现象；大数据量时
   构建过程会转入后台线程并显示"正在构建三维模型"进度提示，等待期间界面仍可响应
5. **低配电脑运行建议**：保持"低功耗模式"开启可让滑动更流畅；调骨阈值时
   按住滑动条拖动为低分辨率预览，松开后自动以全分辨率在后台重建
6. **元数据显示**：若 DICOM 文件元数据异常（如部分定位像写入的层厚），
   软件会自动过滤并在对应位置显示 `-`

## 故障排除

### 无法加载DICOM文件
- 确认文件格式为DICOM（.dcm）
- 检查文件夹权限
- 尝试重新扫描患者列表

### 二维画面全黑
- 确认已加载DICOM数据
- 尝试滚动滚轮或按 ↑ / ↓ 键切换切片
- 按 `R` 键复位到序列默认窗宽窗位
- 右键拖动调整窗宽窗位，或换用工具栏的窗宽窗位预设
- 点击"重置视角"按钮恢复默认视图
- 少数序列的首尾若干层本身就是空气层（该窗下无组织显示），属正常现象

### 3D渲染卡顿
- 开启"低功耗模式"
- 降低骨阈值以减少渲染数据量
- 关闭"去除细小碎屑"选项

### 测量功能异常
- 确保已加载DICOM数据
- 二维：先点测量工具栏里的对应图标（CT值 / 长度 / 角度），再在图上点击
- 三维：先点左下角**立方体+蓝线**按钮进入测长模式，再在模型上点两点
- 按 `Esc` 取消正在进行的测量，或点「清除 / 清测量」按钮清掉重来

### 点「漏检反馈 / 反馈列表」按钮弹出错误（Win7）
- **v1.13.0 已修复**。旧版的原因是桌面快捷方式绕过了启动脚本，
  程序自带的数据库运行库找不到；现在程序启动时会自动补齐。
- 若仍报错，请改用软件目录里的**启动程序.bat**启动程序（不要直接双击
  桌面快捷方式），并确认 `runtime_env.py` 与 `main.py` 在同一目录。
- 反馈数据本身不会丢，程序目录下的 `feedback_images\` 和
  `detection_records.db` 依然有效。

### CPR功能无法使用
- 检查是否已安装numpy和scipy库
- 确保已加载DICOM数据
- 检查控制台输出是否有错误信息

### 操作时提示「程序出错」（v1.7.7 起）
从 v1.7.7 开始，软件**不会再出现"点一下按钮窗口就消失、没有���何提示"**
的情况：任何操作中的意外错误都会弹窗告知，并把完整错误信息写入软件目录的
`error_log.txt`。遇到这类提示时：

1. 先记下弹窗里的错误摘要；
2. 把软件目录下的 **`error_log.txt`** 一并发给技术支持，
   里面有时间戳和完整调用栈，可直接定位；
3. 该文件可累积多次记录，确认问题解决后可自行删除。

### 拖拽缩略图到阅片区没反应
- 确认拖的是**序列卡片**（带缩略图的两行文字），不是患者姓名行；
- 拖动时观察阅片区顶部是否出现**蓝色边框**：出现边框就说明放置目标
  已生效，松手即可加载；没有边框说明鼠标不在阅片区域内；
- 阅片区**整个范围**（含画面正中、三维四视图）都可放置，不必精确对准边缘。

## 更新日志

### v1.24.1 (2026-11-01)

**修掉「第五中节指骨未评级」—— 少一项分级会让骨龄偏低**

- **问题：** 部分片子检测完成后，图上和报告里都写着「第五中节指骨未评级」。
  这一项不是没框到，而是分类置信度没到 0.30 的及格线，被判了「不采信」直接丢掉。
  丢掉等于这一项按 0 分计（该项满分 49 分，总分约 1000），骨龄会因此系统性偏低。
- **原因：** 小指的中节指骨是 13 项里最小、骨骺特征最弱的一项，片子分辨率稍低就
  发虚。模型给的判定其实多数是对的，只是「不敢确信」，置信度常在 0.17~0.29。
  拿统一的 0.30 去卡，正好把它卡掉。
- **现在：** 中节指骨单独放宽门槛，按最佳判定计分，并在图上该等级后面加一个 `?`、
  在报告末尾写明「该项形态显示欠清晰，已按最佳判定分级计分，建议结合临床复核」。
  图上右下角有一行小字解释 `?` 的含义。9 张实测里 MAE 从 0.60 降到 0.39。
- **未分级的那一项现在会明确列出来。** 侧栏关节列表固定显示 13 行，没评上的写
  「未分级（未计入总分）」，报告末尾也会点名并提示「该项缺损会使骨龄偏低，
  必要时请手工补评」。以前这一行是直接从列表里消失，很难察觉少了一项。
- **修正报告的等级写法。** 报告原先写「第三中节指骨骨骺12级」——RUS-CHN 只有 1~8 级，
  没有 12 级。那个数字是内部细分档的序号。现在报告与标注图统一按 RUS-CHN 命名，
  写成「8级」「7（2）级」这样，两边一致，也不会再出现不存在的等级。

### v1.24.0 (2026-11-01)

**骨龄检测完，屏幕上直接就能看到 13 个关节的标注**

- **新：骨龄结果直接标在片子上。** 检测完成后，阅片区显示的影像上会画出 13 个
  关节框，每个框旁边写着关节名、等级和该项得分（例如「第三近节骨骺 6级 S20」）。
  以前这些标注只写进软件目录的 `debug_output`，界面上看不到，没法核对模型框的

- **新：「关节标注」开关。** 侧栏新增可勾选的「关节标注」。取消勾选即切回没有

### v1.9.0 (2026-10-05)
- **新增MRI（MR）检查支持**，与 CT、X 线同列表共存，患者名前缀为 `[MR]`。

**能做什么**

- 二维阅片：逐层翻阅、窗宽窗位调节、缩略图导航、缩放平移，均与 CT 一致；
- MRA 血管三维重建：把 MRA 薄层数据重建成三维血管树，
  可看到 Willis 环（大脑前/中/后动脉）与颈内动脉的立体形态；
- MPR 三正交面（轴位/矢状位/冠状位）同步浏览。

**界面上有什么变化**

- 载入 MR 后，右侧「骨组织阈值 / 骨阈值预设」会换成
  **「血管信号阈值」**，刻度是信号强度而非 CT 的 HU；
- **默认就是血管图**：载入 MRA 后系统会按该序列的强度分布自动算出一个
  合适的阈值，直接切到三维就能看到脑血管树，不需要手动调整；
- 血管阈值也可以手动拖动，或用下拉框预设：
  「自动（推荐）」（默认）/「仅主干 (550)」/「末梢清晰 (380)」/「自定义」；
- **血管强度的合适区间**（本机实测，该批 MRA 186 张 0.5mm 薄层）：

  | 阈值 | 效果 |
  |------|------|
  | < 350 | 阈值过低，会把脑组织一起烧成壳，看不到血管 |
  | 350 ~ 500 | 血管树可用范围 |
  | **400 ~ 450** | **最佳区**，Willis 环与各条动脉清晰、末梢完整 |
  | > 600 | 阈值过高，只剩粗主干，丢失细末梢 |

  不同设备的信号量级不同，所以**不要照抄数字** —— 看「自动」推荐值即可，
  它按你当前这套数据的强度分布算出来，落在最佳区内。
  滑块上悬停也有这个区间说明。

- CT 专用的窗值预设（肺窗/骨窗等）与 **CT 值测量对 MR 自动隐藏** ——
  MR 像素是信号强度而非 HU，套用会导致画面全黑或读数毫无意义；
- 「自动去床板」对 MR 自动关闭（MR 没有 CT 密度可依）。

**几处自动处理，无需你干预**

- **定位像自动跳过**：`gre_scout` 这类定位图不会出现在序列列表里；
- **重建批次自动跳过**：设备中间产物 `3D_Batch1/2`（同一张体数据被
  切成多批渲染）不会被当成断层序列加载；
- **同名序列自动编号**：一次检查里有两个都叫 `tof3d_tra_MRA` 的序列时，
  列表会标成 `tof3d_tra_MRA（1/2）`、`（2/2）` 以便区分；
- **单张序列**（如 MRA 的 MIP 投影图）保留供阅片，但三维入口自动禁用；
- **「概览图 1张」标注**：若某序列只有 1 张、而序列名却是 MRA/T1/T2 这类
  断层或血管序列，说明设备**只导出了概览图**（实测有此情况：同一台设备
  另一位患者的同名序列有完整 186 张薄层）。此时列表会标成
  「概览图 1张 · 设备仅导出概览图」，鼠标悬停也有说明 ——
  这是设备导出内容不全，不是软件解析出错。

**已知限制**

- 血管三维重建目前针对 **MRA（血管成像）** 调优。
  普通 MR 序列（T1/T2/FLAIR/DWI/ADC）建议用二维阅片与 MPR，
  三维重建出来的组织形态参考价值有限。
- 不同设备的 MR 序列命名与信号标定差异较大，若血管三维效果不理想，
  请用「血管信号阈值」滑块手动微调：调高只剩主干，调低纳入更多末梢分支。
- MR 检查暂不接入 AI 辅助诊断（现有模型针对 DR 摄影影像）。

  - 三维模型构建 / 全分辨率重计算转入后台线程并显示进度提示，等待期间界面不再冻结
  - 骨阈值滑动条松手后先在预览分辨率下即时生效，全分辨率在后台自动重建（视角保持不变）
  - 加载序列时目录纯净则直接读取原目录，省去整卷临时拷贝，加载更快
  - 底部缩略图条生成更快；换序列 / 关闭序列后及时释放上一卷占用的内存
- **修复三维重建骨面发灰（光照二次修正）**：骨色亮度恢复原值（此前一次修复
  误把整体光照调暗导致所有部位发灰），仅保留对颅骨刺眼反光的抑制
  （高光系数 0.2→0.08 并收紧高光范围）——骨色与原来一致，颅骨不再反光
- **修复三维重建质量下降 + 床板/U 型托架去不掉（胸部专项修复，最终版）**
  - 质量下降根因：此前版本的「去碎屑」按连通域尺寸一刀切删除，
    会破坏骨表面的噪声壳层（骨盆髂翼、颅骨外板被"掏薄"变碎）。
    现改为**邻接保护**：只剔除远离骨块的漂浮碎屑，骨表面 6 个体素内的
    壳层与细节纹理全部保留（头颅、四肢关节面的细颗粒纹理不受影响），
    并可放心默认开启
  - 「自动去床板」按 **CT 密度双条件**判定：①床材 HU 99 分位 < 600
    （碳纤维板、塑料、泡沫垫、U 型托架等干净床材）；
    ②高密度体素占比 < 0.2% 且 p99 < 1000（胸部检查床与 FOV 边界伪影
    融合成的包裹全患者的巨大壳——它混有少量伪影热像素，单看 p99 会
    漏检，这正是此前"胸部床板去不掉"的根因）。
    真骨普遍有 0.5% 以上的 ≥900 HU 体素，分界余量充足；
    位于身体外侧的床块还向图像外缘整体切除（含支柱/碎段残留）
