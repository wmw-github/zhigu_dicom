# CT三维重建 + X线AI辅助诊断 + MRI阅片 —— 发行版部署说明

版本：**v1.22.2**
打包时间：2026-10-31

---

## 一、这是什么

一套软件，三个能力：

| 模块 | 能力 |
|---|---|
| **CT3D** | CT 阅片（二维）+ 三维重建（骨面/血管/脊柱） |
| **MRI** | MR 阅片（二维 + MPR）+ **MRA 血管三维重建** |
| **X线 AI** | 胸片 / 骨折 / 脊柱侧弯 / 骨龄 / 足弓 五种辅助诊断 |

患者列表**共用** —— CT / DR / MR 患者同屏显示，患者名前带
`[CT]` / `[DR]` / `[MR]` 前缀区分。
X 线只在二维模式显示（X 线无三维重建），AI 按钮集中在右侧工具栏的
「X线 AI 辅助诊断」分组。

### MRI 说明（v1.9.0 新增）
- 载入 MR 后右侧「骨组织阈值」自动换成「血管信号阈值」（信号强度，非 HU）；
- MRA 序列**默认就出血管图**，无需手动调阈值；
- 血管强度合适区间：<350 会把脑组织烧成壳，400~450 最佳，>600 只剩主干。
  数值随设备而异，以界面「自动」推荐值为准；
- CT 专用的肺窗/骨窗预设与 CT 值测量对 MR 自动隐藏；
- 定位像（gre_scout）与设备重建批次（3D_Batch）会自动跳过。

## 二、部署步骤

### 1. 拷贝

把整个项目目录复制到目标电脑（**整个目录一起拷**，不要只拷文件）。
建议路径：`D:\zhigu_dicom` 或 `E:\zhigu_dicom`，**路径尽量不要含空格和中文**。

> 开源版请从本仓库获取源码，或从项目的 Releases 页面下载打包好的分发包，
> 下载后可用 `certutil -hashfile 文件名 SHA256` 核对校验值再解压。
> AI 模型权重不随仓库分发，需按 `xray/app/models/README.md`
> 和 `reportqc/models/README.md` 自行放置。

### 2. 双击安装

运行目录下的 **`install.bat`** → 自动在桌面创建「CT三维重建」快捷方式。

### 3. 启动

双击桌面快捷方式，或直接运行 **`run_env.bat`**。

> `run_env.bat` 会设置 OpenGL / Qt 插件 / onnxruntime 所需的 PATH 与 `QT_PLUGIN_PATH`，
> **必须用它启动**，不能直接双击 `main.py`。

### 4. 后续升级（v1.22.0 起不用再整包拷了）

装好这一版之后，以后升级不用再拷 1.4 GB：

1. 打开软件，右侧「工具区」标题旁的**更新**按钮——启动 6 秒后会自动查一次，
   有新版本时它会变成蓝色的「● 更新」。
2. 点开，确认版本号和更新说明，点「立即升级」。补丁通常几百 KB，十几秒下完。
3. 装完软件自动重开，版本号就是新的了。

细节：

- 只传输变化过的文件。`pyenv\`、AI 模型这些不变的大件不参与传输。
- **检测记录、阈值设置、反馈图片不会被覆盖**，升级只动程序文件。
- 装的过程会先把被替换的文件备份到 `_upgrade_backup\`，
  任何一步失败自动回滚到升级前，软件照常能用。
- 内网限制了外网访问时，检查更新会静默失败（不弹窗、不报错），
  这时找技术支持要**离线升级包**：解压到 `_patch\` 双击 `升级.bat` 即可。

> ⚠️ 从 v1.21.0 或更早版本升到 v1.22.0 这一步，**必须用全量包**——
> 老版本里没有升级模块，装不上补丁。v1.22.0 之后才能走在线升级。

## 三、首次运行会自动做什么

以下都是自动的，无需手工操作：

1. 在 `xray\app\data\` 下创建 `detection_records.db`（**只存文字，不存图像**）
2. 在软件目录下创建 `feedback_images\`（漏检反馈的图片落盘位置）
3. 首次点某个 AI 功能时加载对应 ONNX 模型（约 2.4 秒一次性开销）

## 五、常见问题

**Q：双击没反应 / 一闪而过**
A：改用 `run_env.bat` 启动，错误信息会写到同目录的 `run_env.err.log`。

**Q：提示找不到 OpenGL / 显卡驱动**
A：确认目标机已安装显卡驱动。可尝试更新显卡驱动，或在intel/AMD 官网装 OpenGL 运行库。

**Q：AI 检测报「模型未加载」**
A：`xray\app\models\` 目录必须完整（约 439 MB）。拷贝时不要漏。

**Q：想迁移历史检测记录**
A：`detection_records.db` 可以直接拷贝到新机（同目录覆盖）。
但注意它只含文字结论，不含历史标注图。

**Q：磁盘占用**
A：完整目录约 5.4 GB，其中 Python 环境 4.7 GB + AI 模型 439 MB。
运行后新增数据只有 KB 级（检测记录）和 MB 级（反馈图片）量级。
