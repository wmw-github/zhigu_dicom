# 报告质控功能说明

- 适用版本：v1.22.2 及以后
- 更新日期：2026-10-31

## 一、它是什么

在 CT3D 里常驻一个悬浮小窗口，**自动读取当前写报告界面上的患者信息与报告正文**，
用一套影像报告质控规则做检查，并用颜色告诉你这份报告能不能签。

支持两类写报告界面：**体检登记软件**（项目表格 + 右侧检查结果/诊断建议）
与**标准 PACS 报告软件**（影像所见 / 诊断结果）。两套可以同时用，
各框一次区域，之后按当前前台的软件自动识别。

它不是另一个软件，不切换窗口、不复制粘贴，全程在 CT3D 里完成。

## 二、使用流程

```
程序启动 ──► 小窗自动出现（就绪态，不识别）
                  │
      首次 ──► 点「设置区域」框选一次报告区 ──► 保存到本机 ──► 立即识别
                  │
      以后 ──► 点「刷新」或双击小窗 ──► 按当前软件的区域截图 ──► OCR ──► 质控 ──► 显示结果
```

三步上手：

1. 打开写报告软件，让报告完整显示在屏幕上
2. 在小窗点「设置区域」，拖出一个能**完整框住患者信息 + 报告正文**的矩形
3. 换报告后点「刷新」，或直接双击小窗

**两个写报告软件可以同时用。** 各框一次即可，之后程序按当前在前台的软件
自动选对应的那块区域 —— 在体检登记软件和标准 PACS 之间来回切也不用改设置。

## 三、功能清单

### A. 常驻悬浮小窗

| 功能 | 说明 |
|------|------|
| 启动自动出现 | 程序一打开小窗就在，不用点任何按钮 |
| 悬浮置顶 | 无边框、始终在最上层、不进任务栏，PACS 全屏也不遮住它 |
| 自由拖动 | 按住小窗任意位置拖动，摆到不挡报告的地方 |
| 记住位置 | 下次启动回到上次摆放的位置 |
| 双击刷新 | 双击窗口空白处即重新识别（列表条目和按钮不会误触发） |
| 随时关闭与重开 | 点「×」关闭；主程序左栏「报告质控」可重新唤出 |
| 紧凑不碍事 | 结论胶囊并入标题栏，就绪态整窗约 188px 高（比原版矮 72px），只占屏幕一角 |

### B. 识别区域只设一次

| 功能 | 说明 |
|------|------|
| 框选一次即固化 | 「设置区域」拖出的矩形保存到本机注册表 `HKCU\Software\ZhiGu\CT3D`，重启程序、升级软件都不丢 |
| 一套软件一份区域 | 框选时会记住「这是哪个软件」，每个写报告软件各框一次，互不覆盖 |
| 按前台自动切换 | 点「刷新」时按当前在前台的软件自动选区域；换病人、换标题都不影响（认进程不认标题） |
| 自动校验区域有效性 | 区域小于 20 像素、或坐标落在所有屏幕之外（换显示器后常见），自动判为「未设置」并引导重设，避免截出黑图 |
| 需要时随时重设 | 换了显示器、调整了软件窗口大小，在该软件在前台时点「设置区域」重框一次即可 |
| 框错了能清掉 | 设置窗「常规」页底部的「识别区域」一行可看到已配置了哪几个软件，点「清除」全部重来 |
| 框选可随时取消 | 拖拽中按 ESC、点右键、或误触（框太小）都安全退出，不会卡住 |

### B2. 支持的两类报告界面

| 界面 | 版式特征 | 质控范围 |
|------|----------|----------|
| **体检登记界面** | 左侧「项目编号 / 项目名称 / 检查结果」表格，右侧「检查结果」与「诊断建议」两个文本框 | 表格的检查结果列 + 右侧检查结果 + 诊断建议，**三块全部**检查 |
| **标准 PACS 报告界面** | 「影像所见」与「诊断结果」两个大文本框 | 两个框全部检查 |

程序自动判断是哪种版式，不需要手动切换。患者信息也各按各自界面提取：
体检登记界面的「体检编号」会照原样显示（不叫成「检查号」），方便回软件里检索。


### C. 患者信息提取

从截图里自动提取 15 个字段（另存原始 OCR 行），取不到就留空，**不猜、不填默认值**：

- **小窗患者卡直接显示**：姓名（大字）、性别与年龄、影像号（无则退检查号）、设备、部位、检查项目、检查时间
- **点影像号即复制**：点患者卡第二行，影像号进剪贴板（悬停变亮即表示可点），
  标题栏闪一句「已复制影像号 P2026…」，用不着手抄；没有影像号时自动退到检查号
- **后台同时保存**：检查号、申请号、报告医生、审核医生、影像所见、诊断结论、报告全文

用途是让你一眼确认：**屏幕上这份报告，是不是这位患者的**。

### D. 质控规则（7 类）

| 类别 | 检查内容 | 规则规模 |
|------|----------|----------|
| **危急值** | 命中危急值关键词即报：脑出血/脑疝/主动脉夹层/肺栓塞/心包填塞/消化道穿孔/脊柱骨折/脓毒血症等 | 10 大类标准、49 个关键词 |
| **错别字** | 医学形近字与术语误写，如「膈肌→隔肌」「纵隔→纵膈」「磨玻璃密度→蜜度」 | 内置 57 条（9 个分类）+ 出厂 34 条 + **用户自加（设置窗）** |
| **无意义输入** | 键盘连按、连续重复字符、无元音长串（真乱码才报，见下） | 举证式判定，免维护 |
| **左右矛盾** | 影像所见与诊断结论的侧别不一致；左侧病变写成右侧 | 左/右侧词表各 76 项 |
| **性别相关** | 男性报告出现子宫、卵巢；女性报告出现前列腺、睾丸等 | 器官词表 + 性别推断 |
| **术语匹配** | 模态与术语冲突，如 CT 报告里写「信号」「T1WI」（MR 术语）、MR 报告里写「CT 值」 | 按模态上下文判断 |
| **中文语法** | 句末多余「的/了/着」、词语重复、主谓搭配错误、动宾冗余（「可见…显示」） | 语法模式库 |
| **异常字符** | 只报正文里根本不该出现的字符：不可见控制字符/乱码、`@ # $ ^ \| \` 这类编程符号、同类标点连打 3 个以上 | 举证式判定 |

> **标点不再误报**（v1.19.1）：半角 `, . ( ) : ;`、省略号「……」、数字单位
> `1.2cm×0.9cm` 都属正常写法，一律不报。原来那套「不在白名单就报异常标点」
> 会让几乎每份报告都挂两条无用告警。
| **字段缺失** | 没识别到姓名、影像号或报告正文时给提示 | — |

配套的「不误报」机制：

- 医学白名单：正常医学术语不判为错别字
- 矛盾过滤器：过滤「双肺纹理清晰」「心影大小正常」这类正常描述
- 固有双侧器官词表：36 项，避免把「双肺」「双肾」判成左右矛盾
- **OCR 置信度门控**：错别字所在 OCR 行置信度低于 0.85 时，降级为「识别存疑」而不判错别字——OCR 形近字误认（如把正确的「膈肌」认成「隔肌」）不会当成真错别字报出来
- **英文缩写举证式判定**：影像报告里缩写密度极高（ECT / PICC / TACE / VATS / BI-RADS / Gd-DTPA …）。
  判据不是「不在白名单就算乱码」，而是「**默认是术语，只有出现明确乱码证据才报**」：
  全大写 2~6 字母直接放行，只有键盘连按（asdf/qwer）、连续重复（AAA）、连续 4 个以上辅音这类
  才提示，且降为「提示」级。内置 100+ 项缩写，本院特有缩写可在设置里补。

### E. 颜色提醒（四级）

| 颜色 | 小窗标记 | 含义 |
|------|----------|------|
| 红 | 危急 | 命中危急值，需立即处理 |
| 橙 | 修改 | 有高危问题（错别字、左右矛盾、性别矛盾），签字前必须改 |
| 黄 | 复核 | 中低危问题，建议核对 |
| 绿 | 通过 | 未发现问题 |

（小窗标记用「危急/修改/复核/通过」短文案，历史筛选里对应「危急/需修改/需复核/通过」。）

结论标记（胶囊）就在**标题栏**，一行说完，不再单占一条状态栏：

```
┌────────────────────────────────────────────┐
│ 报告质控  (危急)  2 项危急值 · 1 项待修改    × │
├────────────────────────────────────────────┤
│  李建国                            男 / 62岁 │
│  影像号 P202610240137                       │
│  胸部CT平扫（薄层） · 2026-10-27 09:14        │
├────────────────────────────────────────────┤
│  ● 危急值：肺动脉主干内见充盈缺损…            │
│  ● 疑似错别字：「磨玻璃密度」误写为…           │
├────────────────────────────────────────────┤
│  [刷新] [设置区域] [详情] [历史]      [关闭]  │
└────────────────────────────────────────────┘
```

- 胶囊文案：`就绪`（已设区域待识别）／`···`（识别中）／`未设置`／`危急`／`修改`／`复核`／`通过`／`错误`
- 胶囊右侧的小字是摘要（问题计数、操作提示），过长自动省略，鼠标悬停看全文
- 小窗**不显示识别区域的尺寸坐标**（设过就不用管它，医生不看这个数）
- 就绪态整窗高约 197px，摆在 PACS 角落不挡报告
- 患者卡每一行都是**单行显示**：部位、检查项目、时间很长时中间用「…」省略
  （时间在末尾，所以省略号在中间、时间始终看得见），鼠标悬停看全文。
  这样任何长度都不会把文字折到卡片外面压住下面的问题列表
- 部位与检查项目内容重复时只显示一次（「胸部」+「胸部CT平扫」→ 只留后者）

**危急值不弹窗、不打断。** 这是刻意设计：阅片过程中弹窗会打断操作，红色胶囊 + 问题条目已足够醒目。

### F. 详情与误判反馈

点小窗「详情」，打开完整问题列表：

| 功能 | 说明 |
|------|------|
| 逐条问题 | 每条显示等级、问题描述、修改建议、触发原文片段 |
| 原文定位高亮 | 在报告全文中高亮问题片段，按等级上色，不用自己找 |
| 标记为误报 | 判定规则报错了，一键标记，**系统自动学下该关键词，之后不再提示它** |
| 确认有问题 | 确认是真问题，同样留档 |
| 忽略该词 | 这个词以后不再报（如本院固定缩写），进入忽略词表 |
| OCR 置信度显示 | 每条问题附带对应 OCR 行置信度；「识别存疑」类问题单独提示 |

### F2. 三种「不再提示」机制的区别

用户看到误报时有三条路，作用范围和撤销方式不同，别混用：

| 方式 | 入口 | 记住什么 | 什么时候用 |
|------|------|----------|------------|
| **标记为误报** | 详情窗 | 该条问题的**关键词**（如「隔肌」），自动学习 | 最常见。规则判断错了，以后同类都别报 |
| **忽略该词** | 详情窗「忽略该词」 | 指定的一个词，进忽略词表 | 这个词你们医院本来就这么写，不是错 |
| **自定义错别字 / 术语白名单** | 设置 → 自定义规则 | 错词→正确写法、或医学术语 | 主动补规则，不依赖误报触发 |

三者都是**立即生效**：下一次点「刷新」就按新规则跑，不用重启程序。
所有条目都能在「设置 → 自定义规则」里查看和删除（删除即恢复检查）。

### G. 历史记录

| 功能 | 说明 |
|------|------|
| 自动存档 | 每次检测结果自动入库，含患者信息、等级、全部问题、报告全文、耗时 |
| 三种筛选 | 按患者姓名/影像号、按结论等级（危急/需修改/需复核/通过）、按时间范围（今天/近 7 天/近 30 天/近一年/全部） |
| 表格浏览 | 一眼看到历次检测的时间、患者、等级、问题数 |
| 查看详情 | 双击任意记录，回到当时的完整问题列表与原文 |
| 导出 CSV | 导出当前筛选结果，`utf-8-sig` 编码，Excel 双击打开不乱码 |

### H. 设置

设置窗分两个页签：**常规**（日常偏好）和**自定义规则**（本院专属写法）。

| 页签 | 设置项 | 说明 |
|------|--------|------|
| 常规 | OCR 放大倍数 | 截图小字识别不清时调高（默认 2 倍） |
| 常规 | 提示级问题显示 | 决定「提示」级（低危）问题是否出现在小窗列表里 |
| 常规 | 忽略词管理 | 增删忽略词，删除后该词恢复检查 |
| 自定义规则 | **自定义错别字** | 错词 → 正确写法 + 级别，存表后立即参与检测（与内置 57 条并存） |
| 自定义规则 | **医学术语白名单** | 英文缩写/术语，加入后不再被判为「无意义字母」 |
| 自定义规则 | **误判学习词** | 标记误报后自动积累，可查看、可撤销 |

设置里也提供「重设识别区域」入口（左栏「质控设置」）。

### I. 与主程序的集成

- 左栏三个按钮：**报告质控**（唤出/置顶小窗）、**质控历史**、**质控设置**
- 程序关闭时，小窗、框选遮罩、各对话框一并清理，不留浮窗残骸
- OCR 推理在后台线程运行（每次约 1~3 秒），**检测期间主程序照常操作，不卡界面**

## 四、功能边界（明确不做的事）

| 不做 | 原因 |
|------|------|
| 不弹窗警告危急值 | 阅片过程弹窗会打断操作，按要求只做颜色提示 |
| 不做 AI 语义检测 | 纯规则路线；AI 路线需 torch/sentence-transformers，与 Win7 绿色包不兼容 |
| 不改写报告 | 只提示问题与建议，修改仍在 PACS 里由医生完成 |
| 不上传任何数据 | 全部在本机完成，截图与识别结果不联网 |
| OCR 不是 100% 准确 | 形近字仍可能误认，已用置信度门控压制误报；关键信息请以原文为准 |
| 乱码检测会漏掉少量全大写乱码 | 采用「举证式」策略后，全大写且无键盘序列、无连续重复的乱码（如 `QWERTZ`）会被放过。这是「宁可漏报也不误报缩写」的取舍；报告里的真乱码绝大多数是小写误触，仍能检出 |
